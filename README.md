# 手机语音输入电脑 · VoiceInput2PC

**不买麦克风、不传音频流，直接用口袋里的手机输入法向电脑光标位置安全口述文字。**

</div>

复用安卓手机现成输入法完成语音转文字，通过 HTTPS、专用令牌与证书指纹固定（跨网内置 Tailcat/WireGuard 数据面）将确认文本加密送达 Windows 接收端，以 Unicode 键盘输入直接打入绑定窗口光标处。

## 值得关注的技术

- 应用层 HTTPS + 专用令牌 + 证书指纹固定，内置 Tailcat/WireGuard 跨网络加密通道
- Windows 端绑定目标窗口并进行 Unicode 键盘输入，不占剪贴板，支持剪贴板反向取回手机
- 安卓端零麦克风权限且不传音频，v0.6.1 候选版内置按需扫码配对、自动路径探测与连接诊断

## 当前进度

源码、候选包与已发布成品分开查看：请以 Releases 实际文件及各分支说明为准。语音识别由用户选择的手机输入法承担；不包含本地尚未发布的离线识别改造。
