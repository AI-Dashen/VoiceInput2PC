# Contributing

Contributions are welcome when they preserve the project's authorization,
privacy, release-integrity, and backward-compatibility controls.

By submitting a contribution, you agree that it is licensed under this
repository's MIT License and certify the Developer Certificate of Origin 1.1
with a `Signed-off-by` line. The certificate is published at
https://developercertificate.org/ and does not transfer copyright ownership.

Do not submit credentials, pairing material, private logs, signing keys,
generated packages, third-party binaries, or code you do not have the right to
contribute. New bundled dependencies must include their source, version,
checksum, license, and redistribution obligations.

Run the relevant automated tests before opening a pull request. Changes to
pairing, transport, update, file-transfer, or release packaging require both
positive and failure-path tests.
