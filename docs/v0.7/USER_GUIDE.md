# 万能输入法 v0.7 使用说明

## 安装与配对
安装“万能输入法-v0.7-测试版.apk”。包名 io.github.amxooo.voiceinput2pc.v07test，版本0.7.0-testing，版本号8。可更新之前的本地v0.7工程版；与官方旧版分开安装，不覆盖旧版数据。本地版需自己的配对信息。
电脑接收端启动后，手机扫描或粘贴完整配对码。内置扫码按需申请相机权限；也可用系统相机或粘贴，语音由你现有输入法负责。

## 输入
扫码成功后进入新的正文编辑页，不是原工程版界面。顶部显示电脑名称，点击可切换已配对电脑；右上“历史”打开输入记录。
先在电脑选好输入框，再点“开始输入”。在手机正文区调用输入法语音或键盘，确认文字后持续传到电脑当前光标。需要停止时点“暂停输入”，不需要每次“新一段”。
正在组成或批量修改的文字不会提前发送。修改已发送部分会暂停：电脑已有内容不自动删改。按“核对后恢复”核对两端文本，避免重复输入。

## 断线与回执
断线后保留原消息编号、内容、顺序与会话，最多进行两次自动重连。可点“停止重连”。只有明确返回已输入且没有手动暂停、退到后台或编辑冲突，才继续原会话。
无法确认、仅保存或会话过期时保持暂停，用户核对后恢复；不盲目重新发送已处理内容。接收端版本未声明顺序协议时使用兼容路径。

## 历史与导出
手机“历史”：关键词、开始日期、结束日期查询，分页浏览，不限制总保留条数。每条记录包含时间、来源、逻辑会话、修订、目标设备、状态及正文。
点击“导出”选择TXT/Markdown/JSON/CSV，系统文件选择器选择保存位置，例如下载目录。导出全部匹配记录，不只导出当前页，不包含配对令牌。返回输入页保留草稿，输入保持暂停。
Windows“全部历史”也可关键词/时间查询、分页、四格式完整导出。

## 更多
正文页“•••”：历史、电脑选择/名称、发送文件、连接方式、连接诊断、核对恢复、使用说明。文件发送继续复用原功能；接收电脑文字会替换手机草稿并暂停，不自动回传。
自动连接优先局域网，必要时通过内置Tailcat，恢复后定期尝试返回局域网；不需要额外安装完整Linux系统。

## 电脑新版
Windows更新代码在“万能输入法-v0.7-Windows接收端源码.zip”。需Windows构建为新接收端后，才具备本版的当前焦点、顺序去重和历史窗口。现有旧电脑EXE不会因手机更新自动获得这些改动。
在Windows项目目录创建.venv，按requirements.txt安装依赖，保留原可信vendor/tailcat/windows/tailcat.exe，然后运行scripts/build_windows_release.ps1 -Version 0.7.0。新下载依赖须由用户确认；默认构建脚本不自动获取Tailcat。

## 验收安排
用户决定自行做最终验收，不再自动开关手机软件。已停止界面自动测试。手机输入法实际行为、真实电脑输入、窗口切换、跨网络及Windows GUI需用户实测。本说明不是验收通过声明。
