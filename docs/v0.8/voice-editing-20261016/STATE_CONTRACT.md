# 语音编辑入口与输入检测契约

本条取代0.8.8/0.8.9“录音或识别完成后才展开删除回车”的旧行为。

| 条件 | 编辑键可见 | 编辑键可用 | 麦克风动作 |
|---|---|---|---|
| 语音主界面、已绑定同一输入框、连接存在 | 是 | 是 | 点击开始收音 |
| 收音/识别中 | 是 | 否 | 点击停止/取消，沿用原事务 |
| 没有输入框/连接断开/目标已变化 | 是（语音窗口仍在时） | 否 | 阻止向失效本机目标收音 |
| 远端草稿 | 是 | 按绑定/远端ACK及发送策略 | 不用本机光标推断远端就绪 |
| 更多菜单 | 两侧编辑键暂隐，中心入口保留 | 使用真实菜单 | 长按打开，关闭后编辑键立即可用 |
| 密码等敏感框 | 沿用普通安全键盘 | 原敏感输入策略 | 不启动语音/光标监控请求 |

当前输入连接、当前EditorInfo和session目标身份一起校验；selection=-1或requestCursorUpdates不支持不能被当作断连。解绑后invalidate旧识别generation，晚到回调不能继续写旧目标。点击执行时也检查本机编辑就绪状态。

光标通过Android事件requestCursorUpdates(IMMEDIATE|MONITOR)、onUpdateCursorAnchorInfo/onUpdateSelection更新；只保存本会话选区和可见性元数据，不轮询截图、不调用模型、不导出宿主正文。HOST_REPORTED_VISIBLE表示宿主报告，不等于已验证屏幕像素。没有位置报告即UNKNOWN，不能猜、不能凭空补画光标。更多→设置展示真实输入检测与光标报告状态。

主语音窗口/更多/设备选择统一固定280dp（可用屏幕不足时限高）；避免按百分比放置的子View再反向撑大WRAP_CONTENT窗口。普通键盘恢复WRAP_CONTENT、沿用固定候选区。只在几何确实变化时requestApplyInsets，避免无变化布局重复申请。

系统绑定测试采用fresh无障碍节点并等待连续3帧几何稳定，不能把入场动画早期缓存bounds与展开后新bounds直接比较。历史失败不改判成功。
