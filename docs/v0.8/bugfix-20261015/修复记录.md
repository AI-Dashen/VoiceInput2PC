# 九宫格、删除和输入法切换修复

日期：2026-10-15
状态：代码、定向自动测试、离线构建通过；新包真机复测 PENDING。

用户两张截图显示Termux输入行有数字串，以及当前输入法为本产品时切换入口消失。后者已由HomeActivity条件分支确认；数字串和删除问题按终端InputConnection兼容路径修正，需安装后复现验证，不能将静态分析当成真机根因已完全证明。

- 九宫格不向宿主发送临时组字；只有选择候选才确认输出。
- TYPE_NULL或Termux编辑器不走setComposingText，保留面板内组字。
- Termux删除使用DEL键事件；普通编辑器保留选区、码点删除路径。
- 当前已选择本输入法时，Home保留“切换其他输入法”；现有功能页增加切换入口。

验收：九宫格输入数字序列但不选词，宿主不得出现数字；选中文词后点删除；语音上屏后删除；切换其他输入法再切回。以上在Termux和普通文本框分别复测。系统默认输入法不由脚本强制修改，用户经系统选择器选择。
