## 修复范围

1. 左侧“语音”直接开始录音；已有草稿时显示“续说”并追加下一段。
2. 右侧按状态显示“停止 / 识别中 / 上屏”。上屏成功后读取宿主 `EditorInfo`，恢复“发送 / 搜索 / 完成 / 下一步 / 前往 / 回车”。

4. 首次5秒没有人声自动退出；人声出现前PCM不送入本地识别核心。

6. 最终结果后的400毫秒防误触窗口阻止“停止”触摸穿透为“上屏”。
