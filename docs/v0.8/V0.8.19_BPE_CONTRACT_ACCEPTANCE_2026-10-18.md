# 万能输入法 v0.8.19 BPE 无关的模型标记修复

日期：2026-10-18  
版本：versionCode 29 / `0.8.19-bpe-contract`

## 根因

v0.8.18 只按独立 Token ID 识别 `<内容|A>`。模型采用 BPE，词表真实存在把空格和 `<` 合并的 Token 等替代编码；因此相同的可见字符串不保证由单字符 Token 组成，真人输出仍会漏过 Token 状态机。

## 修复

保留 Token 级解析，并在 BPE 解码后的最终 UTF-8 文本增加第二层精确状态机：

- 支持标记位于正文中间、连续出现和同段多次出现；
- 仅接受 `<非空内容|A>`；
- 保留载荷文字，移除协议外壳及协议分隔空格；
- 未闭合、未知类别、嵌套、空载荷和超长结构原样保留；
- 不使用宽泛正则，不全局屏蔽合法符号。

真人失败原句已作为自动测试：

`<嗯，|A>我现在测试一下。就这样。还是会出来，你好，<嗯，|A>啊。`

预期：

`嗯，我现在测试一下。就这样。还是会出来，你好，嗯，啊。`

## 安装目标纠正

此前 Debug 默认自动附加 `.v08probe`，而 v0.8.17/v0.8.18 构建时又显式清空后缀，造成正式包与旧测试包并存，Android未把它们视为同一应用。现已把默认 Debug 目标改为正式包；只有显式传入 `-PqaPackageSuffix=.v08probe` 才会生成隔离测试包。最终 Package Manager 仅保留正式用户包 `io.github.amxooo.voiceinput2pc` versionCode 29。
