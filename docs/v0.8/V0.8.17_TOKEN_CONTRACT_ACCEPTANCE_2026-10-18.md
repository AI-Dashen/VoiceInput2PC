# 万能输入法 v0.8.17 模型标记协议修复

日期：2026-10-18  
设备：OnePlus 15 / Android 16 / ARM64  
版本：versionCode 27 / `0.8.17-token-contract`

## 用户发现

独立 ASR 执行器在真人短语音和语气词场景偶发把模型内部结构直接上屏：

- `<嗯 |A>`
- `<啊，|A>`

原运行库未出现该显示，因此 v0.8.16 的输出协议兼容性不完整。

## 根因证据

词表回读确认这些字符不是 `add_special_tokens.txt` 的特殊 Token，而是普通输出 Token：

- `<` = 529
- `>` = 531
- `|` = 593
- `A` = 534
- `嗯` = 22900
- `啊` = 4527

当前独立执行器采用逐步 argmax，直接把普通 Token 拼成文本；原运行库另有 beam、`punc_token_ids` 和结果整理配置。固定公开 WAV 不覆盖语气词结构，因此此前完全对拍不能证明所有输出协议已经兼容。

## 修复

新增独立的 Token 级后处理器。仅当**整个识别片段**严格匹配：

`529 (<) → 1..16 个内容 Token → 593 (|) → 534 (A) → 531 (>) → 可选 EOS`

才拆除外层协议并保留内容及标点。尾部协议分隔空格 Token 722 被移除。

以下内容全部原样保留：

- 正文中嵌入的 `<...|A>`；
- 未闭合结构；
- 未知类别；
- 嵌套分隔符；
- 超过长度边界的结构。

未采用宽泛字符串正则，也未屏蔽 `<`、`>`、`|` 的模型输出能力。
