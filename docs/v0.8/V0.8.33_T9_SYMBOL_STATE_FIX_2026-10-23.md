# 0.8.33 九宫格与符号状态修复

日期：2026-10-23
分支：`fix/v0833-t9-symbols-state`
版本：`0.8.33-t9-symbols-fix` / versionCode 43

## 修复内容

- 九宫格左上键由含糊的 `@#` 改为明确的 `分词`。
- 数字页的下一层入口明确标为 `符号`；符号首页直接提供 `@ # & % / \\ _ - + = * ￥ $ ？ ！`，常用逗号和句号继续保留在底栏。
- 中文组合中点击标点时，先明确提交当前首个真实候选，再追加标点；没有真实候选时保留原输入并提示。
- 16位只作为解码窗口边界，不再触发自动选词。后续物理按键进入可恢复队列；用户明确选词、空格或回车后，队列再装入下一段。
- 删除键优先删除尚未送入解码器的排队按键。
- 模式、语音和功能页切换遇到未确认组合时保持原状态并提示，不自动选择、不清空。
- 只隐藏纯数字/分隔符组成的九宫格内部查询码；`2号楼`、`3D打印` 等真实混合候选允许显示。

- Java 主代码与 Android instrumentation 测试源码已编译。
