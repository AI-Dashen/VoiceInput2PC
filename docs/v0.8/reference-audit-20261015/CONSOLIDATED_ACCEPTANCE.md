# 万能输入法 v0.8.2 合并交付与验收

日期：2026-10-15。当前确认的键盘/语音草稿/本机历史修复已合并构建并安装，不再让用户逐阶段安装。

## 完成的操作闭环

| 操作 | 实现与实际检查 |
|---|---|
| 默认输入方式 | 普通文本字段默认显示语音；密码和数字字段按字段类型处理；不自动开启麦克风 |
| 九宫格 | 真实Rime候选，逐段音节选择、改选、撤销；已选字锁定；输入数字不写宿主 |
| 语音后继续编辑 | 草稿保留，26键/九宫格/英文/数字/符号修改同一草稿；真实候选插入草稿中间通过 |
| 再说一段 | 在当前光标或选区插入，不要求先上屏；保留前后文本 |
| 结束与失败 | 静音6秒结束，识别15秒兜底；临时隐藏保存可见partial并拒绝旧回调；空录音可重试 |
| 上屏 | 明确确认才提交；提交失败/异常保留草稿；成功后清空，重复点不重复写入 |
| 删除 | 草稿选区、Unicode字符、宿主文本分层；长按重复删除，松手停止 |
| 切换字段 | 新字段清旧草稿，旧识别回调不能回写；同字段重建与功能页返回保留编辑 |
| 记录 | 本机成功提交接入原SQLite；失败/密码/禁止学习字段不记；同文不同事件独立，重试去重 |
| 查询与导出 | 日期、字面搜索、分页、TXT/MD/CSV/JSON；中文来源/状态与记录字符量；不冒称净输入统计 |
| 切换输入法 | 保留系统输入法选择入口，不因选择本输入法而消失 |
| 跨设备 | 保留既有目标/发送流程，语音草稿修改不碰已待发内容；本轮未接真实电脑回归 |
