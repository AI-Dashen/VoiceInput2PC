## 实现
- 共享 LeafIconStyle：鲜叶绿 #51C832、透明中心、窄亮边及深浅背景双描边。麦克风、删除、回车及快捷图标共用样式；录音红色、识别琥珀色。管理页面使用同源清晰线性图标，避免所有图标发光造成干扰。
- 26键统一浅色键帽、细边框、按压反馈和右侧单手操作列；保留已有连续拼音、字母回车与编辑逻辑。
- HomeActivity 单页整合实际记录统计、记录查询/展开/复制/分页/来源日期筛选/导出、电脑配对与输出选择、本地语音与键盘权限设置。旧入口转入对应展开区；电脑收取文字/发送文件工具仍可打开。
- 统计、列表、导出复用同一来源过滤器，不迁移数据库。
- 导入电脑仅注册，不自动改当前输出；待发状态比较完整配对信息；后台恢复重新显示检查控件，并保留手填配对码。
- 记录导出采用跨Activity的原子互斥，防止旋转或重复点击同时写入。
