## 真实缺陷

v0.8.17 只处理整段 `<内容|A>`。用户真人口述证明相同结构会插入正常正文，并且一次结果中可能多次出现：

`<嗯，|A>我现在测试一下。就这样。还是会出来，你好，<嗯，|A>啊。`

因此 v0.8.17 的修复范围不足。

## 修复

后处理器改为从 Token 序列头到 EOS 逐项扫描。每次只识别精确结构：

`529 (<) → 1..16 个内容 Token → 593 (|) → 534 (A) → 531 (>)`

命中后仅移除协议外壳并保留内容；随后继续扫描剩余正文，因此支持内嵌和多次出现。未知类别、未闭合、嵌套、空载荷和超长结构仍原样保留。没有使用字符串正则，也没有全局禁用 `<`、`>`、`|` 等合法字符。
